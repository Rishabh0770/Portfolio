# Rishav Kumar — Portfolio
Static site (HTML + CSS + vanilla JS). Open `index.html` or deploy the folder on Netlify/Vercel.

## How to edit
- **Projects:** `js/projects.js` (add `long` and `features` for a richer detail page)
- **Blog posts:** `js/blog.js` (add new post at the top of `POSTS`)
- **Styles:** `css/style.css`

Pages: `index.html`, `project.html?id=<slug>`, `blog.html`, `post.html?slug=<slug>`
